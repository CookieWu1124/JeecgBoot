# 提案改善 — 微信开发者工具 0-1 教程

> **适用对象**：完全没接触过微信小程序 / 微信开发者工具的同事  
> **目标**：在电脑上跑起本仓库的 `spex-app` 小程序，测通「工号 + 微信授权登录」  
> **创建日期**：2026-08-31  
> **关联**：[移动端本地联调指南.md](./移动端本地联调指南.md)（H5 / Apifox）· [微信授权登录-生命周期脉络.md](./微信授权登录-生命周期脉络.md)（号码从哪来、码何时产生）

按章节从上往下做即可。每一步都写了「你会看到什么」和「做错了会怎样」。

## 0. 先建立三个概念（30 秒）

本项目同一套 `spex-app` 代码，可以编成两种东西：

| 产物 | 怎么打开 | 能不能测微信授权 |
|------|----------|------------------|
| **H5** | Chrome 打开 `http://localhost:9000` | **不能**。点「微信授权登录」只会提示去小程序里用 |
| **微信小程序** | 用 **微信开发者工具** 打开编译后的目录 | **能**。这是本文要走的路 |

**微信开发者工具**不是写代码的 IDE（代码仍在 Cursor / VS Code 里改）。它只干三件事：

1. 在电脑上模拟微信里的小程序窗口  
2. 帮你调微信接口（`wx.login`、手机号授权）  
3. 把模拟器画面投到手机上（真机预览）

关系可以记成：

```text
你改 spex-app 源码
        ↓  pnpm run dev:mp
生成 dist/dev/mp-weixin（这才是「小程序项目」）
        ↓  用微信开发者工具打开这个目录
模拟器里出现「提案改善」登录页
        ↓  请求打到本机后端
http://127.0.0.1:8080/jeecg-boot
```

## 1. 开始前准备好这些

下面缺一样，后面都会卡住。请先打勾。

- [ ] 电脑能上网；已安装 **微信 PC 版** 或手机微信（用来扫码登录开发者工具）
- [ ] 本仓库能编译：已安装 **Node.js ≥ 20** 和 **pnpm**（H5 能 `pnpm run dev` 就说明这块 OK）
- [ ] **JeecgBoot 后端已启动**，浏览器能打开：`http://localhost:8080/jeecg-boot/doc.html`
- [ ] 后端 `application-dev.yml` 里已配置 `jeecg.wx-mini.app-id` / `app-secret`（不要写进小程序前端）
- [ ] 有一个测试员工：`sys_user` 里工号、密码、**手机号**都填好了

- [ ] 你的微信号已被小程序管理员加为 **开发者**（见第 3 节）。没有这个权限，开发者工具会报 AppID 无权限

本项目小程序 AppID（已写在 `spex-app/env/.env` 的 `VITE_WX_APPID`）：

```text
wxce3a1b42d7fa0bd6
```

**不要**把 AppSecret 配到前端或开发者工具里。Secret 只放后端。

## 2. 安装微信开发者工具

### 2.1 下载

打开官网（认准微信官方，不要下第三方打包）：

https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

Windows 选 **稳定版 → Windows 64**。下载得到类似 `wechat_devtools_x.x.x_win32_x64.exe` 的安装包。

> macOS 选稳定版 macOS。下文以 Windows 为主，Mac 差异会单独注明。

### 2.2 安装

1. 双击安装包，一路下一步即可。  
2. **建议保持默认路径**（后面自动打开工具会用到）：

```text
C:\Program Files (x86)\Tencent\微信web开发者工具\
```

3. 若你改过安装目录，记下自己的路径，第 5 节会用到。

安装完成后桌面应有图标：**微信开发者工具**。

## 3. 第一次打开：扫码 + 开服务端口

### 3.1 用微信扫码登录

1. 打开「微信开发者工具」。  
2. 会出现二维码。用 **手机微信** 扫码，在手机上点允许。  
3. 登录成功后进入工具主界面（可能先看到「新建项目 / 导入项目」）。

扫码的必须是 **已被加为这个小程序开发者** 的微信号。用错号会在导入项目后报「没有权限」。

### 3.2 让本仓库能自动打开工具（强烈建议）

`pnpm run dev:mp` 编译完成后，会尝试自动拉起开发者工具。这需要打开「服务端口」：

1. 顶部菜单：**设置 → 安全设置**（有的版本在 **设置 → 通用设置 → 安全**）  
2. 打开开关：**服务端口**  
3. 关掉设置窗口即可，不必改端口号

没开这个开关时：编译仍会成功，只是不会自动弹出工具。你可以按第 6 节手动导入，功能一样。

## 4. 确认你是这个小程序的开发者

**不要自己注册一个公众平台。** 个人新注册的小程序会得到另一个 AppID，和本仓库 `application-dev.yml` 里的公司 AppID 不是同一个；你在自己后台把自己加成开发者，对公司这个小程序没有任何权限。

要开发的是公司已有的小程序（AppID `wxce3a1b42d7fa0bd6`）。后台仍是 https://mp.weixin.qq.com/ ，但必须由 **该公司小程序的管理员** 登录后，把你的 **微信号**（扫码登录开发者工具的那个微信）加进去：

1. 登录公众平台 → 选中对应小程序  
2. **成员管理 → 项目成员 → 添加成员**  
3. 权限至少勾选 **开发者**（能预览、能用开发者工具）

你自己不是管理员时，把微信号发给管理员加一次即可。加完后重新扫码登录开发者工具。

同时请管理员确认已开通 **手机号快速验证组件**（登录要用 `getPhoneNumber`）：

- 公众平台 → **开发管理 → 接口设置**（或「开发 → 开发管理」）  
- 找到「手机号」相关能力，按提示开通  
- 未开通时：点「微信授权登录」会失败或拿不到 `phoneCode`

本地开发者工具模拟器有时能用测试手机号绕过；**真机必须开通**。

## 5. 编译小程序（在 Cursor / 终端里做）

代码不在微信开发者工具里改。打开本仓库终端：

```powershell
cd c:\workspace\IDEA\spex-inside\spex-app
pnpm i
pnpm run dev:mp
```

第一次会较慢。成功后终端大致会出现：

- 编译完成  
- 正在打开微信开发者工具（若第 3.2 步开了服务端口）  
- 或提示打开失败，并打印要导入的目录

**真正给开发者工具用的目录是：**

```text
c:\workspace\IDEA\spex-inside\spex-app\dist\dev\mp-weixin
```

注意：

- 这个命令会 **一直挂着**（和 `pnpm run dev` 一样）。改源码会自动重新编译，开发者工具里点编译或等它刷新即可。  
- **不要**把 `spex-app` 根目录当成小程序项目导入，必须导入上面的 `dist\dev\mp-weixin`。  
- 若自动打开失败，看终端里的 CLI 路径。安装不在默认位置时，编辑 `spex-app/env/.env`，取消注释并改成你的路径：

```text
WECHAT_DEVTOOLS_CLI_PATH = 'C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat'
```

改完再跑一次 `pnpm run dev:mp`。仍然失败就走第 6 节手动导入，不影响联调。

若终端报 `pages.json->pages/index/index duplication`：这是本地生成的 `src/pages.json` 里首页写了两遍（H5 能编过、小程序会挂）。删掉 `spex-app/src/pages.json` 后再执行 `pnpm run dev:mp` 即可（该文件在 `.gitignore` 里，会自动重新生成）。

## 6. 在开发者工具里导入项目（自动没打开时必做）

1. 微信开发者工具 → **导入项目**（或「+」）  
2. 填写：

| 项 | 填什么 |
|----|--------|
| 目录 | 选 `spex-app\dist\dev\mp-weixin`（必须能看到里面的 `app.json`、`project.config.json`） |
| AppID | `wxce3a1b42d7fa0bd6`（不要用「测试号」，否则授权对不上公司后台） |
| 项目名称 | 随意，例如 `提案改善` |

3. **后端服务**必须选 **不使用云服务**（不要选「微信云开发」，本项目后端是本机 JeecgBoot）。  
4. 勾选底部协议后点 **创建**。

「不校验合法域名」**不在这个导入窗口，也不在右上角齿轮（通用/外观/代理/安全）里**。必须先点创建，等项目打开后再改，见第 7 节。

若提示「未找到 app.json」：目录选错了，多半选成了 `spex-app` 而不是 `dist\dev\mp-weixin`。先确认第 5 步编译已成功。

## 7. 必须改的两项本地设置

点 **创建** 之后，会进入带模拟器的主界面（左边手机画面，右边是代码/调试器）。这时再找「不校验合法域名」：

1. 看窗口 **最上方工具栏右侧**（模拟器上方那一排按钮，不是导入页的齿轮）  
2. 点 **详情**（有的版本写成「Details」）  
3. 弹出的面板里切到 **本地设置**  
4. 勾选：**不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**

路径记成：`项目已打开 → 右上角「详情」→「本地设置」→ 勾选不校验合法域名`。

不勾的话，模拟器访问 `http://127.0.0.1:8080` 会被微信拦截，登录接口全失败。上线后不能靠这个勾选；正式版必须在公众平台配置 HTTPS 合法域名。

关上面板后如未自动刷新，点一次 **编译**。

### 7.2 确认 AppID

同一「详情」里，AppID 应为 `wxce3a1b42d7fa0bd6`。  
若显示测试号或空，改回来后重新编译。

### 7.3 编译模式

顶部应选 **普通编译**，模拟器选一个常见机型即可（如 iPhone 或默认）。  
第一次建议用 **模拟器**，通了再真机。

点工具栏 **编译**。左侧模拟器应出现「提案改善」登录页：工号输入框、登录按钮、底部「使用工号+微信授权登录」切换。

- 目录确实是 `dist\dev\mp-weixin`  
- 点一次「清缓存 → 全部清除」再编译

## 9. 先测「工号 + 密码」（验证小程序能打到后端）

小程序默认是微信授权模式。先切到密码，确认网络没问题：

1. 点登录卡片下方：**使用工号+密码登录**  
2. 输入已有工号和密码（例如联调账号 `600081` / `123456`，以库里实际为准）  
3. 点 **登录**

**成功**：进入工作台 / 首页。  
**失败**：先不要测微信。按下面查：

| 现象 | 原因 | 处理 |
|------|------|------|
| Network 里请求失败 / 超时 | 后端没开，或地址不对 | 浏览器先打开 `http://localhost:8080/jeecg-boot/doc.html` |
| `url not in domain list` | 没勾「不校验合法域名」 | 回第 7.1 步 |
| 401 / 用户名密码错误 | 账号不对 | 管理端确认该工号能登录 |
| 跨域或 404 | 请求没打到本机 `/jeecg-boot`（例如打到了 `laf.run`） | 调试器 **Network** 里看完整 URL，应为 `http://127.0.0.1:8080/jeecg-boot/sys/mLogin`；改完 `getEnvBaseUrl` 后等 `dev:mp` 重新编译再试 |

密码登录通了，说明：**开发者工具 → 本机 8080** 这条链路是好的。

## 10. 再测「工号 + 微信授权」（本文重点）

### 10.1 测试前核对手机号

管理端打开该员工，看 `sys_user.phone`：

- 必须是 **11 位手机号**  
- 必须等于 **你扫码登录开发者工具的那个微信** 所绑定的手机号  

对不上会提示找管理员改手机号，这是产品规则，不是工具坏了。

若该员工以前绑过别的微信，管理端用户列表 → **更多 → 解绑微信**，再测。

### 10.2 操作步骤

1. 若已登录，先在小程序里退出（退出只清本地 Token，不会解绑）。  
2. 回到登录页，切到 **使用工号+微信授权登录**（小程序默认就是这个）。  
3. 只填 **工号**，不要填密码。  
4. 点绿色按钮 **微信授权登录**。  
5. 弹出微信手机号授权：

   - **模拟器**：可能出现「允许」/ 自定义手机号面板。选允许；若能填测试号，填成和 `sys_user.phone` 一样的号码。  
   - **真机**：出现微信官方授权页，点允许。手机号以微信绑定号为准，填不了假号。

6. 等跳转工作台。

### 10.3 两种正常结果

| 情况 | 后端在做什么 | 你看到的 |
|------|----------------|----------|
| 这个微信 **已经绑过** 该工号 | `silentLogin` 直接发 Token | 可能一进登录页就进工作台，或点授权后立刻进入 |
| **第一次** 用这个微信 | `bind`：校验工号 + 微信手机号是否同一人，再写绑定 | 授权成功后进入工作台 |

绑定关系存在表 `sys_third_account`（`third_type = wechat_mp`）。退出登录 **不会** 删这条记录。

### 10.4 授权失败怎么看

开发者工具 → **调试器 → Network**，找：

- `POST .../sys/wxMini/silentLogin`  
- `POST .../sys/wxMini/bind`

点开看响应 `message`。常见情况：

| 提示 / 现象 | 含义 | 怎么办 |
|-------------|------|--------|
| 微信授权请在小程序中使用 | 你在 H5 / Chrome 里点的 | 必须用本文的开发者工具，不要用 `pnpm run dev` 的 9000 端口 |
| 工号与微信手机号不匹配 | 严校验失败 | 把 `sys_user.phone` 改成该微信真实手机号 |
| 获取手机号失败 / `phoneCode` 无效 | 授权码过期或未开通手机号能力 | 再点一次授权；确认公众平台已开通；不要把授权码当手机号 |
| `invalid appid` / `invalid secret` | 后端 `wx-mini` 配错 | 改 `application-dev.yml` 后 **重启后端** |
| `code been used` | `jsCode` 只能用一次 | 重新编译 / 重新点授权，不要拿旧 code 重放 |
| 没有权限使用该 AppID | 当前扫码微信号不是开发者 | 回第 4 节加成员 |

后端控制台若出现请求微信 `jscode2session` 或 `getuserphonenumber` 的错误，把完整报错留下即可排查。

## 11. 真机预览（模拟器拿不到手机号时再做）

模拟器对 `getPhoneNumber` 支持不稳定。授权弹窗异常、或一直拿不到手机号时，改真机：

1. 手机和电脑连 **同一 Wi-Fi**。  
2. 开发者工具点 **预览**，出现二维码。  
3. 用 **已加为开发者的微信** 扫码（普通好友微信扫不开开发版）。  
4. 真机访问本机后端时，`127.0.0.1` 是手机自己，**不是你的电脑**。需要改小程序请求地址：

   - 查电脑局域网 IP（PowerShell：`ipconfig`，看无线/以太网的 IPv4，例如 `192.168.1.23`）  
   - 改 `spex-app/env/.env`：

```text
VITE_SERVER_BASEURL__WEIXIN_DEVELOP = 'http://192.168.1.23:8080/jeecg-boot'
```

   - 保存后等 `dev:mp` 重新编译，开发者工具再点一次预览。  
   - Windows 防火墙需放行 **8080**。  
   - 仍勾选「不校验合法域名」。

测完本地、改回 `127.0.0.1`，避免别人机器连错地址。

## 12. 日常改代码怎么刷新

| 你改了什么 | 怎么看到效果 |
|------------|----------------|
| `spex-app` 前端 | `dev:mp` 会自动编译；开发者工具一般会自动刷新，没有就点 **编译** |
| Java 后端 | 重启 JeecgBoot；开发者工具不用重装，重新点登录即可 |
| `env/.env` 里的地址 / AppID | 需要重新编译小程序（`dev:mp` 会编）；必要时开发者工具「清缓存」 |

不要在开发者工具里改 `dist/dev/mp-weixin` 里的文件，下次编译会被覆盖。改 `spex-app/src`。
