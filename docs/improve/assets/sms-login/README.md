## 价值说明

该图是 **工号 + 登记手机 + 短信验证码** 登录的产品级参考流程，并包含 HR 校验、openid 占用、Redis 限流与落库时机。实现与联调以本图为准。

| 用途 | 说明 |
|------|------|
| 产品对照 | 发码调 HR；登录用 Redis 快照；openid 后端用 `code` 换 |
| 与微信授权并存 | 开发期保留 `/sys/wxMini/*` 与密码登录；短信为新增通道 |
| HR 字段口径 | 见 [api/HR员工校验接口-联调清单.md](../../api/HR员工校验接口-联调清单.md) |
| 阿里云短信开通 | 见 [阿里云短信服务开通配置手册.md](../../阿里云短信服务开通配置手册.md) |

## 关键约定（与口述对齐后）

1. **后端**调 HR，前端不传员工档案包。  
2. **后端**用微信 `code` 换 openid，不接受前端直传 openid。  
3. 发码与登录各换一次 `code`。  
4. 绑定冲突在发码阶段即检查；登录再验 openid 防中途换号。  
5. 退出只清 Token，不解绑 `sys_third_account`。  
6. 三级审批者写入员工档案，**不**自动覆盖提案委员会配置。
