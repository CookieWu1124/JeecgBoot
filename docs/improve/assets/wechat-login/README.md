# 微信小程序 — 登录绑定流程图（产品参考）

> **来源**：业务侧 spexSys 原型资料（波哥提供）  
> **归档日期**：2026-09-02  
> **文件**：[登录绑定流程图.png](./登录绑定流程图.png)

## 价值说明

该图是 **微信授权登录 / 工号绑定** 的产品级参考流程，与后端 `/sys/wxMini/*` 设计对齐，建议长期保留：

| 用途 | 说明 |
|------|------|
| 产品对照 | 静默 OpenID、唯一计费点（取手机号）、退出仅清 Token 不解绑 |
| 前后端分工 | 哪些步骤在前端、哪些在后端、何时调 `silentLogin` / `bind` |
| 与现网差异 | 本仓库 spex-app **方案 A** 在「主动退出后再进」有意跳过静默，便于联调切密码；见 [progress/01_application_DEV_PROGRESS.md](../../progress/01_application_DEV_PROGRESS.md) |
| 给另一套小程序 | 按此图实现即可直接对接现有后端，无需改接口 |

## 图例速查

| 形状/颜色 | 含义 |
|-----------|------|
| 蓝色圆角 | 流程步骤 |
| 绿色圆角 | 成功态（进工作台 / 发 Token） |
| 红色圆角 | 失败 / 拦截 |
| 黄色菱形 | 判断分支 |
| 虚线 | 退出后再进回路 |
| 蓝框橙标 | **唯一计费点**（`getPhoneNumber` → `getuserphonenumber`，约 0.03 元/次） |

## 与本仓库后端接口映射

| 流程图节点 | 后端接口 |
|------------|----------|
| 静默获取 OpenID | `POST /sys/wxMini/silentLogin` |
| 工号有效（绑定前粗校验） | `POST /sys/wxMini/checkWorkNo` |
| 微信授权获取手机号 + 写入绑定 | `POST /sys/wxMini/bind` |
| 退出仅清 Token | `GET /sys/logout`（不解绑；绑定在 `sys_third_account`） |
| 管理端解绑 | `POST /sys/wxMini/unbind` |
