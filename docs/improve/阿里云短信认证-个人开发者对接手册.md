# 阿里云短信认证 — 个人开发者对接手册（免企业资质）

> **适用**：个人实名阿里云账号、**无营业执照 / 无企业资质**，开发测试阶段要发登录验证码。  
> **产品**：号码认证服务（PNVS）里的 **短信认证**（API 域名 `dypnsapi.aliyuncs.com`）  
> **官方原文**：[个人开发者如何接入短信验证码服务](https://help.aliyun.com/zh/pnvs/use-cases/sms-verify-for-individual-developers)  
> **日期**：2026-09-05  
> **对照**：企业自定义签名/模板 + Jeecg `DySmsHelper`（`dysmsapi`）见 [阿里云短信服务开通配置手册-企业资质经典短信服务.md](./阿里云短信服务开通配置手册-企业资质经典短信服务.md)

**安全提醒**：AccessKey 勿提交 Git；个人仓只用占位符，本机或外置配置覆盖。

## 0. 先分清两个产品（同事能过、你卡在签名管理，多半卡在这）

| | **短信认证**（本手册 · 个人推荐） | **短信服务 / 国内短信**（企业手册） |
|--|----------------------------------|-------------------------------------|
| 控制台 | [号码认证 → 短信认证](https://dypns.console.aliyun.com/) | 短信服务 → 国内消息 → 签名/模板管理 |
| 个人无企业资质 | **可以**，免申请签名/模板 | **很难**：须企业资质与自定义签名审核 |
| API | `SendSmsVerifyCode` / `CheckSmsVerifyCode` | `SendSms`（Jeecg `DySmsHelper`） |
| Endpoint | `dypnsapi.aliyuncs.com` | `dysmsapi.aliyuncs.com` |
| 签名模板 | **系统赠送**，不可自定义新建 | 自己申请签名 + 模板 CODE |
| 套餐 | 号码认证侧单独购买/赠送，**与短信服务套餐不互通** | 短信服务套餐 |

官方说明摘要：经典「短信验证码 / 短信服务」须企业资质且不支持个人资质；个人应走 **短信认证**。见[官方文档](https://help.aliyun.com/zh/pnvs/use-cases/sms-verify-for-individual-developers)。

你若在「短信服务 → 添加签名」填企事业单位，个人号会卡住——**请关掉那个页，改走本手册。**

## 1. 你最终要拿到的东西（清单）

| 项 | 从哪拿 | 用途 |
|----|--------|------|
| AccessKey ID / Secret | RAM 用户（永久 AccessKey） | 调 `dypnsapi` |
| 系统赠送签名名称 `sign_name` | 短信认证控制台（预置，不可改） | `SendSmsVerifyCode` |
| 系统赠送模板编号 `template_code` | 同上，须与赠送签名**配套** | `SendSmsVerifyCode` |
| （可选）套餐包 | 号码认证控制台购买/赠送 | 正式调用计费 |

赠送签名与赠送模板必须配对，不可「自定义签名 + 赠送模板」交叉。

## 2. 开通步骤

### 2.1 账号

1. 阿里云账号已完成 **个人实名认证**。  
2. 打开 [号码认证服务控制台](https://dypns.console.aliyun.com/) → 开通 **短信认证**（按控制台引导同意协议）。

### 2.2 RAM 与 AccessKey

1. [访问控制 RAM](https://ram.console.aliyun.com/users) → **用户** → **创建用户**。  
2. 勾选 **使用永久 AccessKey 访问**（旧称「OpenAPI 调用访问」）。  
3. 保存 AccessKey（Secret 只显示一次）。  
4. 授权：联调可先挂号码认证 / 短信认证相关权限（控制台策略名以现网为准，常见含 `Dypns` / 号码认证字样）；**不要**只挂 `AliyunDysmsFullAccess` 就以为能调 `dypnsapi`——那是经典短信服务权限。  
5. AK 只放本机环境变量或本地 yml，勿 push。

也可参考官方：[创建 AccessKey](https://help.aliyun.com/document_detail/53045.html)。

### 2.3 在控制台确认赠送资源

1. 进入 **短信认证** 概览 / 服务配置（界面可能含「快速测试」）。  
2. 记下系统赠送的：  
   - 签名名称（如测试签名文案，以控制台为准）  
   - 验证码模板 CODE  
3. 可用「快速测试」绑定测试手机号，先确认能收到短信（与 API 同源产品）。

新手指引另见官方：[短信认证服务新手指引](https://help.aliyun.com/zh/pnvs/)（以控制台文档入口为准）。

## 3. API 怎么用（与提案短信登录的关系）

### 3.1 两个核心接口

| 接口 | 作用 |
|------|------|
| [SendSmsVerifyCode](https://help.aliyun.com/zh/pnvs/developer-reference/api-dypnsapi-2017-05-25-sendsmsverifycode) | 向手机发送验证码 |
| [CheckSmsVerifyCode](https://help.aliyun.com/zh/pnvs/developer-reference/api-dypnsapi-2017-05-25-checksmsverifycode) | 核验验证码（系统生成码时用） |

发送时必填大致包括：`phone_number`、`sign_name`（赠送签名）、`template_code`（赠送模板）。详见官方 API。

SDK：Java 等见官方 [dypnsapi SDK](https://next.api.aliyun.com/api-tools/sdk/Dypnsapi?version=2017-05-25&language=java-tea&tab=primer-doc)；Endpoint 固定 **`dypnsapi.aliyuncs.com`**。

### 3.2 自定义验证码（贴合本仓库简化版流程）

官方 FAQ：

- 可通过参数传入自定义 **4～6 位**数字验证码。  
- **自定义码时，`CheckSmsVerifyCode` 不能用来校验**，须业务侧自己存、自己比（例如 Redis 票据）。  
- 若用系统自动生成码，可用阿里云闭环校验。

本仓库短信登录定稿（[简化版流程](./assets/sms-login/手机短信验证登录流程-简化版.md)）是：

1. 业务自己生成 6 位码；  
2. 写入 Redis 票据（含 openid、HR 快照）；  
3. 短信通道只负责把码送到手机；  
4. 登录时只比 Redis，**不调通道校验接口**。

→ 个人开发期对接时，应走 **`SendSmsVerifyCode` + 自定义 Code + 自建 Redis 比对**，与简化版一致。  
→ **不要**指望现成 Jeecg `DySmsHelper`（`dysmsapi.SendSms`）直接打通个人短信认证；实现阶段需单独适配 `dypnsapi`（或企业资质就绪后改用企业手册那条经典短信）。

### 3.3 其它限制（官方）

- 仅支持中国大陆手机号（国家码 `86`）。  
- 发送失败不计费（以官方当前规则为准）。  
- 短信认证与经典短信服务套餐**不可共享**。

## 4. 控制台快速自测（不写代码）

1. 打开短信认证 → **快速测试**。  
2. 使用系统赠送签名 / 模板。  
3. 绑定并选择测试手机号 → 发送。  
4. 手机收到后再考虑 API / 工程接入。

## 5. 与提案改善工程的落地建议

| 阶段 | 建议 |
|------|------|
| 现在（个人号） | 按本手册开通短信认证；RAM AK + 赠送签名/模板；控制台快速测试通 |
| 写短信登录代码时 | 发码通道调 `dypnsapi.SendSmsVerifyCode`（自定义 code）；校验走 Redis（简化版） |
| 公司企业资质就绪后 | 可改走经典短信服务 + `DySmsHelper`，见企业手册；配置与套餐切换时注意 endpoint 与权限 |

开发期：**微信授权 / 小程序密码仍保留**；短信为正式目标态通道。

## 6. 常见踩坑

| 现象 | 原因 | 处理 |
|------|------|------|
| 「添加签名」要营业执照 / 他用委托书 | 进了经典 **短信服务** | 改用本手册 **短信认证** |
| Jeecg `/sys/sms` 发失败 | `DySmsHelper` 调的是 `dysmsapi` | 个人期不要用该链路测短信认证；或等企业签名 |
| 赠送签名 + 自己申请的模板 | 官方禁止交叉 | 签名与模板都必须用系统赠送那一对 |
| 有短信服务套餐但认证发不出 | 套餐不互通 | 在号码认证侧买/用短信认证套餐 |
